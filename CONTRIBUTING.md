# Contribuições

Descreva o problema, as versões exatas, passos de reprodução, resultado esperado e resultado observado. Indique se o teste ocorreu em KSP real, num harness ou somente no núcleo. Execute o núcleo com `dotnet run --project tests/Tests.csproj -c Release`; use `build.ps1` com instalações locais para validar os vínculos externos.

Use universos e jogadores de teste com dados fictícios. Antes de abrir uma issue, remova nomes pessoais, IPs/hostnames, caminhos de usuário, senhas, tokens, IDs de naves reais e dados de terceiros dos trechos de log. Anexe somente o menor exemplo necessário. Não envie `Universe`, saves, configurações reais, assemblies do KSP, mods ou arquivos descompilados proprietários.

Contribuições ao código são recebidas sob GPL-3.0, a licença do projeto. Preserve atribuições existentes. Explique o teste relevante e mantenha a documentação das limitações fiel ao que foi executado.
